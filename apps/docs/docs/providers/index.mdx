# Model Providers

Mirror VS is a capable coding agent, but it needs an LLM provider to do the actual thinking. Think of Mirror VS as the brain and the provider as the energy drink — one doesn't work without the other.

Some AI coding tools lock you into a specific provider regardless of what the market looks like. Mirror VS is **model-agnostic** — you choose the model that fits your budget, skill profile, codebase, and mood on any given Tuesday.

Mirror VS supports connecting to a wide range of model providers, giving you the freedom to pick your poison.

Learn how to set up your provider in [the Mirror VS VS Code extension here](/getting-started/connecting-api-provider).

## Overwhelmed by choice?

Yeah, it's a lot. Here's the cheat sheet:

- **Want access to many models?** Try [OpenRouter](/providers/openrouter) for a single API to 100+ models
- **Want to optimize for specific models?** Use the first-party provider for each of them (Anthropic, OpenAI, etc)
- **Looking for local/offline models?** Check out [Ollama](/providers/ollama) or [LM Studio](/providers/lmstudio)
