# Installing Mirror VS

Mirror VS is a VS Code extension that brings AI-powered coding assistance directly to your editor. Install using one of these methods:
1. **VS Code Marketplace (Recommended)** - fastest method for standard VS Code and Cursor users
2. **Open VSX Registry** - for VS Code-compatible editors like VSCodium

---

## VS Code Marketplace

1. Open VS Code
2. Access Extensions: Click the Extensions icon in the Activity Bar or press `Ctrl+Shift+X` (Windows/Linux) or `Cmd+Shift+X` (macOS)
3. Search for "Mirror VS"
4. Select "Mirror VS"  and click **Install**
5. Reload VS Code if prompted

After installation, find the Mirror VS icon (<KangarooIcon />) in the Activity Bar to open the Mirror VS panel.

## Open VSX Registry

For VS Code-compatible editors without Marketplace access (like VSCodium and Windsurf):

1. Open your editor
2. Access the Extensions view
3. Search for "Mirror VS"
4. Select "Mirror VS"  and click **Install**
5. Reload if prompted

<img src="/img/installing/installing-3.png" alt="Open VSX Registry with Mirror VS extension ready to install" width="400" />

## Manual Installation from VSIX

If you prefer to download and install the VSIX file directly:

1. **Download the VSIX file:**
   * Find official releases on the [Mirror VS GitHub Releases page](https://github.com/ReflectAIs/mirror-vs/releases)
   * Download the `.vsix` file from the latest release

2. **Install in VS Code:**
   * Open VS Code
   * Access Extensions view
   * Click the "..." menu in the Extensions view
   * Select "Install from VSIX..."
   * Browse to and select your downloaded `.vsix` file

## Troubleshooting

<img src="/img/installing/installing-4.png" alt="VS Code Output panel showing Mirror VS logs for troubleshooting" width="100%" />
*VS Code Output panel showing Mirror VS logs for troubleshooting*

**Extension Not Visible**
* Restart VS Code
* Verify Mirror VS is listed and enabled in Extensions
* Try disabling and re-enabling
* Check Output panel for errors (View → Output, select "Mirror VS")

**Installation Problems**
* Ensure stable internet connection
* Verify VS Code version 1.84.0 or later
* If VS Code Marketplace is inaccessible, try the Open VSX Registry method
