# Installing Mirror VS

Mirror VS is a VS Code extension — so installing it is refreshingly boring and straightforward. Pick your poison:

1. **VS Code Marketplace (Recommended)** — the fast lane for standard VS Code and Cursor
2. **Open VSX Registry** — for editors like VSCodium that play by their own rules

---

## VS Code Marketplace

1. Fire up VS Code
2. Hit the Extensions icon in the Activity Bar, or smash `Ctrl+Shift+X` (Windows/Linux) / `Cmd+Shift+X` (macOS)
3. Search for "Mirror VS"
4. Click that shiny **Install** button
5. Reload if VS Code politely asks you to

Once installed, look for the Mirror VS icon (<KangarooIcon />) in the Activity Bar. Click it. That's where the fun begins.

## Open VSX Registry

For editors that don't play nice with the Marketplace (looking at you, VSCodium and Windsurf):

1. Open your editor
2. Find the Extensions view
3. Search for "Mirror VS"
4. Click **Install**
5. Reload if prompted (it's like turning it off and on again — it works)

<img src="/img/installing/installing-3.png" alt="Open VSX Registry with Mirror VS extension ready to install" width="400" />

## Manual Installation from VSIX

For the control freaks among us (we see you, and we respect you):

1. **Grab the VSIX:**
   - Head to the [Mirror VS GitHub Releases page](https://github.com/ReflectAIs/mirror-vs/releases)
   - Download the `.vsix` file from the latest release

2. **Install it:**
   - Open VS Code
   - Go to Extensions view
   - Click the "..." menu (top of the Extensions panel)
   - Select "Install from VSIX..."
   - Pick your downloaded file and go

## Troubleshooting

<img src="/img/installing/installing-4.png" alt="VS Code Output panel showing Mirror VS logs for troubleshooting" width="100%" />
*The Output panel — your first stop when things go sideways*

**Extension Not Visible?**
- Restart VS Code (the classic fix)
- Check that Mirror VS is listed and enabled in Extensions
- Try the ol' disable-and-re-enable dance
- Peek at the Output panel (View → Output, select "Mirror VS")

**Installation Problems?**
- Make sure you have an internet connection (yes, we had to say it)
- VS Code version 1.84.0 or later, please
- If the Marketplace is throwing a tantrum, try the Open VSX route
