# Code Actions

Code Actions give you instant access to Mirror VS's AI brain directly in your editor — no need to switch to the chat panel. Think of it as having a senior developer sitting next to you, peering at your code, and offering helpful suggestions through VS Code's lightbulb system.

<div style={{ marginTop: '20px' }}></div>

---

## What are Code Actions?

Code Actions appear as a lightbulb icon (💡) in the editor gutter — that little area to the left of your line numbers. You can also access them via right-click or keyboard shortcut. They pop up when:

- You select a range of code
- Your cursor lands on a line with a problem (error, warning, or hint)
- You invoke them via command

Click the lightbulb, right-click and select "Mirror VS", or use the keyboard shortcut (`Ctrl+.` or `Cmd+.` on macOS) to reveal a menu of available actions.

## Mirror VS's Code Actions

Mirror VS provides 5 code actions, though availability varies by context:

### Context Menu Actions (Right-Click)

- **Add to Context:** Quickly adds selected code to your chat with Mirror, including filename and line numbers. It's first in the menu for a reason — you'll use it a lot.
- **Explain Code:** Asks Mirror to explain what the selected code does. Perfect for deciphering that function your predecessor left behind.
- **Improve Code:** Asks Mirror to suggest improvements. Because we all write code that could be better.

### Additional Actions

- **Fix Code:** Available through the lightbulb menu and command palette (not right-click). Asks Mirror to fix problems in selected code.
- **New Task:** Creates a new task with the selected code. Available through the command palette.

### Context-Aware Actions

The lightbulb menu intelligently shows different actions based on your code's current state:

**For Code with Problems** (when VS Code shows red/yellow squiggles):
- **Fix Code** — Get step-by-step guidance to resolve the specific error or warning
- **Add to Context** — Add the problematic code to Mirror's context for discussion

**For Clean Code** (no diagnostics):
- **Explain Code** — Get detailed explanations of what the code does
- **Improve Code** — Receive optimization suggestions and best practices
- **Add to Context** — Add the code to Mirror's context for further work

For more details on how diagnostics are integrated with Code Actions, see [Diagnostics Integration](/features/diagnostics-integration).

### Add to Context Deep Dive

The **Add to Context** action is listed first because it's the MVP of the group. When you use it, Mirror VS includes the filename and line numbers along with the selected code. This helps Mirror understand the exact context of your code within the project.

Pro tip: Use `Cmd+K Cmd+A` (Mac) or `Ctrl+K Ctrl+A` (Windows/Linux) to add selection to context quickly. See [Keyboard Shortcuts](/features/keyboard-shortcuts).

**Example Chat Input:**

```
Can you explain this function?
@myFile.js:15:25
```

*(Where `@myFile.js:15:25` represents the code added via "Add to Context")*

## Using Code Actions

Three ways to summon them:

### 1. From the Lightbulb (💡)

1. **Select Code** — Select the code you want to work with.
2. **Look for the Lightbulb** — A lightbulb icon appears in the gutter next to your selection (or the line with the error).
3. **Click the Lightbulb** — Opens the Code Actions menu.
4. **Choose an Action** — Pick the desired Mirror VS action.
5. **Review and Approve** — Mirror proposes changes in the chat panel. You decide.

### 2. From the Right-Click Context Menu

1. **Select Code** — Highlight what you want to work with.
2. **Right-Click** — Open the context menu.
3. **Choose "Mirror VS"** — A submenu appears with available actions.
4. **Choose an Action** — Pick your poison.
5. **Review and Approve** — Same dance as above.

### 3. From the Command Palette

1. **Select Code** — You know the drill by now.
2. **Open Command Palette** — `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (macOS).
3. **Type "Mirror VS"** — Filter the commands, then choose the relevant action.
4. **Review and Approve** — Every hero needs a sidekick. You're the approver.

## Terminal Actions

Mirror VS also provides actions for terminal output:

- **Terminal: Add to Context** — Adds selected terminal output to your chat
- **Terminal: Fix Command** — Asks Mirror to fix a failed terminal command
- **Terminal: Explain Command** — Asks Mirror to explain terminal output or commands

Available when you select text in the terminal and right-click. Your terminal output, now AI-actionable.

## Disabling/Enabling Code Actions

You can control Code Actions through VSCode settings:

### Enable/Disable Code Actions

- **Setting**: [`mirror-vs.enableCodeActions`](vscode://settings/mirror-vs.enableCodeActions)
- **Default**: Enabled
- **Description**: Controls whether Mirror VS quick fix options appear in the editor

To access this setting:

1. Open VSCode Settings (`Ctrl/Cmd + ,`)
2. Search for "enableCodeActions"
3. Toggle the checkbox

## Customizing Code Action Prompts

You can customize the prompts used for each Code Action by modifying the "Support Prompts" in the **Prompts** tab. This lets you fine-tune the instructions given to the AI model:

1. **Open the Prompts Tab** — Click the <Codicon name="notebook" /> icon in the Mirror VS top menu bar.
2. **Find "Support Prompts"** — You'll see prompts for "Enhance Prompt", "Explain Code", "Improve Code", and "Fix Code".
3. **Edit the Prompts** — Modify the text. Prompts use placeholders like `${filePath}`, `${selectedText}`, and `${diagnostics}`.
4. **Click "Done"** — Changes saved. You're now a prompt engineer.

### Example Prompt Template

```
Please explain the following code from ${filePath}:

${selectedText}
```
