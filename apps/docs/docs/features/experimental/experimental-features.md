# Experimental Features

Mirror VS includes experimental features that are still under development. Think of them as the "beta channel" — they might be unstable, change significantly, or vanish in future versions. Use them with caution and maybe keep a backup handy.

**Warning:** Experimental features may have unexpected behavior, including potential data loss or security vulnerabilities. Enable them at your own risk. You've been warned (but also, this is where the cool stuff lives).

---

## Enabling Experimental Features

To enable or disable experimental features:

1. Open the Mirror VS settings (<Codicon name="gear" /> icon in the top right corner)
2. Go to the "Advanced Settings" section
3. Find the "Experimental Features" section
4. Toggle away

---

## Current Experimental Features

The following experimental features are currently available:

- [Custom Tools](/features/experimental/custom-tools) — Define TypeScript/JavaScript tools that Mirror VS can call like built-in tools
- [Background Editing](/features/experimental/background-editing) — Work uninterrupted while Mirror VS edits files in the background
- [Concurrent File Edits](/features/experimental/concurrent-file-edits) — Apply multiple file edits simultaneously
- [Image Generation](/features/image-generation) — Generate images from text prompts and save them to your workspace
- [Run Slash Command](/advanced-usage/available-tools/run-slash-command) — Execute predefined slash commands for templated instructions and workflow automation
